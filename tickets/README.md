# PHOENIX Execution Tickets

Codex executes one bounded ticket at a time.

Before a meaningful ticket, read:
1. `/AGENTS.md`
2. `/RULES.md`
3. `/MENTAL_MODEL.md`
4. `/INVARIANTS.md`
5. `/MASTER_SPEC.md`
6. Relevant `/docs/*.md`
7. Current ticket
8. Existing code/tests

Do not skip incomplete dependencies without explicit authorization.
