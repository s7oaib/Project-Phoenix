# 20 — UI/UX Specification

## Main screens

- Onboarding
- Home/Chat
- Agent Network
- Task Graph
- Memory
- Files/Documents
- Computer Control
- Research
- Media
- Permissions
- Models
- Voice
- Settings
- Observability/Developer

## Home

Show PHOENIX status, voice state, chat, text input, microphone control, active task summary, active agents, and model/provider status.

## Agent network

Show alias, professional role, state, current task, and model/provider when useful.

## Permission prompts

Show requested action, agent, resource, reason, risk, duration/scope, and approve/deny controls.

## Accessibility

Keyboard navigation, readable contrast, transcripts/captions, and text alternatives for all voice interactions.
